# Nynycleans Website

## About

This is the official website for **Nynycleans**, a professional residential and commercial cleaning service.

The website is designed with a clean, luxury, soft-feminine style and is mobile-friendly.

## How the Quote Form Works

When a customer submits the form, the website creates an email containing their cleaning information.

The email includes:

* Customer name
* Phone
* Email
* Requested service
* Preferred date
* Bedrooms
* Bathrooms
* Additional notes

The customer can then send the request through their email application.

## Publishing the Website

The website can be uploaded to a free website-hosting service that supports static HTML websites.

Upload:

`nynycleans_website.html`

If the hosting service requires the homepage to be named `index.html`, rename:

`nynycleans_website.html`

to:

`index.html`

Then upload the file to the website host.
